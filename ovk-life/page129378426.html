Политика конфиденциальности
Общие положения

Настоящая политика конфиденциальности определяет порядок обработки и защиты персональных данных пользователей сайта.

Оператор персональных данных

Индивидуальный предприниматель Цегельнюк Артур
(далее — Оператор)

Персональные данные, которые обрабатываются

Оператор может обрабатывать следующие данные:
— имя
— номер телефона
— адрес электронной почты
— иные данные, переданные пользователем через формы сайта

Цели обработки персональных данных

— обработка заявок с сайта
— связь с пользователем
— консультации по услугам
— выполнение обязательств перед клиентом

Правовые основания обработки

Обработка персональных данных осуществляется на основании согласия пользователя.

Порядок обработки и хранения

Персональные данные обрабатываются с соблюдением требований законодательства РФ и не передаются третьим лицам без согласия пользователя, за исключением случаев, предусмотренных законом.

Использование файлов cookie

Сайт использует файлы cookie и сервисы аналитики (в том числе Яндекс.Метрика) для улучшения работы сайта и анализа поведения пользователей.

Защита персональных данных

Оператор принимает необходимые организационные и технические меры для защиты персональных данных.

Права пользователя

Пользователь имеет право:
— запросить информацию о своих данных
— потребовать их удаление
— отозвать согласие на обработку
