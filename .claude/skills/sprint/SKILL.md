# /sprint — Статус спринта

Найди и покажи статус текущего (или указанного) спринта.

## Шаги

1. **Найти спринт-файлы:**
   ```bash
   ls docs/implementation/sprints/SPRINT-*.md
   ```

2. **Определить текущий спринт** (последний по номеру или указанный аргументом).

3. **Прочитать спринт-файл** и показать:
   - Название и цель спринта
   - Прогресс: X из Y задач выполнено
   - Список задач с их статусами (✅ / 🔄 / ⏳)
   - Оставшиеся задачи

4. **Вывести сводку:**

```
📋 Sprint-XX: [Название]
━━━━━━━━━━━━━━━━━━━━━━━━━━
Прогресс: ██████░░░░ X/Y (XX%)

✅ Выполнено:
  - Задача 1
  - Задача 2

🔄 В работе:
  - Задача 3

⏳ Ожидает:
  - Задача 4
```
