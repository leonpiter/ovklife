# Sprint-17: Геостраницы — 13 городов Ленинградской области

> **Статус:** ⏳ Ожидает
> **Ветка:** `feature/sprint-17-geo-pages`
> **Зависимости:** Sprint-05 (шаблоны услуг), Sprint-08 (контакты), Sprint-15 (миграция)
> **Результат:** 13 геостраниц, шаблон page-geo.php, LocalBusiness Schema с geo-координатами

---

## Контекст

Геолокационные страницы — мощный инструмент локального SEO для Яндекса. Каждый город/район ЛО = отдельная посадочная страница, таргетирующая запросы «инженерные системы + [город]». Конкуренты не используют этот подход — это наше преимущество.

**Источник:** `docs/semantic/SEMANTIC_CORE.md` → Кластер 7 — Геостраницы
**Шаблон:** `docs/semantic/SEO_STRATEGY.md` → Шаблон страницы геолокации

---

## Ключевые решения

| Решение | Обоснование |
|---------|-------------|
| Отдельный URL-префикс /geo/ | Не конфликтует с /uslugi/, чистая семантика |
| WordPress Page + кастомный шаблон | Управление контентом через WP-админку |
| Яндекс.Карта на каждой странице | Локальный SEO-фактор, визуальное подтверждение зоны работы |
| Уникальный контент для каждого города | Не дублирование, а специфика региона |

## Чеклист задач

### 1. Шаблон геостраницы
- [ ] Создать `templates/page-geo.php` — WordPress Page Template «Геостраница»
- [ ] Структура секций через `get_template_part()`:
  - `template-parts/geo/section-intro.php` — лид с описанием региона
  - `template-parts/geo/section-services.php` — услуги в городе (ссылки)
  - `template-parts/geo/section-objects.php` — объекты в районе (из CPT project)
  - `template-parts/geo/section-advantages.php` — почему мы в этом регионе
  - `template-parts/geo/section-map.php` — Яндекс.Карта + населённые пункты
  - `template-parts/geo/section-faq.php` — FAQ специфичные для гео
  - `template-parts/geo/section-cta.php` — CTA-блок

### 2. Мета-поля для геостраниц
- [ ] Добавить мета-поля в `inc/meta-fields.php` (или создать `inc/geo.php`):
  - Название города
  - Название района
  - Geo-координаты (широта, долгота)
  - Список населённых пунктов (textarea)
  - Специфика региона (textarea)
- [ ] Нет необходимости в отдельном CPT — используем WordPress Pages с шаблоном

### 3. Schema.org для геостраниц
- [ ] Обновить `inc/seo.php` — LocalBusiness Schema с geo-данными:
  - `areaServed`: название города/района
  - `geo`: GeoCoordinates (широта, долгота)
  - `address`: PostalAddress
- [ ] BreadcrumbList: Главная → Регионы → [Город]

### 4. Яндекс.Карта
- [ ] Интеграция Яндекс.Карты API (или iframe) в `section-map.php`
- [ ] Метка на карте: офис/зона обслуживания
