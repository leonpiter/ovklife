> **Статус:** ⏳ Ожидает

## Контекст

Для полноценного сайта и E-E-A-T (Google) нужны служебные страницы: О компании (авторитетность), Контакты (LocalBusiness Schema + карта), Отзывы (доверие + Review Schema). Privacy и Соглашение уже есть в Tilda-экспорте — перенести.

---

## Ключевые решения

| Решение | Обоснование |
|---------|-------------|
| О компании с фото команды | E-E-A-T: экспертность, опыт |
| Яндекс.Карта на контактах | Локальный SEO-фактор для Яндекс |
| Отзывы с Review Schema | Rich snippets: звёзды в выдаче |
| Структурированные контакты | Парсинг поисковиками |
