# Sprint-09: Рекламные лендинги для Яндекс.Директ

> **Статус:** ⏳ Ожидает
> **Ветка:** `feature/sprint-09-ad-landings`
> **Зависимости:** Sprint-03 (главная страница, компоненты)
> **Результат:** шаблон рекламного лендинга, 4 лендинга под ключевые запросы

---

## Контекст

Уникальное конкурентное преимущество — отдельная посадочная страница под каждый рекламный запрос в Яндекс.Директ. Конкуренты ведут весь трафик на одну страницу. Мы создадим индивидуальные лендинги с точным попаданием в потребность пользователя → выше конверсия, ниже стоимость заявки.

**Лендинги НЕ индексируются** (`noindex`) — это только для контекстной рекламы.

---

## Ключевые решения

| Решение | Обоснование |
|---------|-------------|
| WordPress Page Template | Создание лендингов через WP-админку без кода |
| noindex на лендингах | Не конкурируют с основными SEO-страницами |
| Общие компоненты из Sprint-03 | Переиспользование секций (Hero, CTA, услуги) |
| Уникальный Hero под запрос | Заголовок точно совпадает с поисковым запросом |
| UTM-параметры | Отслеживание эффективности каждого лендинга |

## Чеклист задач

### 1. Шаблон лендинга
- [ ] Создать `templates/landing.php` — WordPress Page Template «Рекламный лендинг»
- [ ] `<meta name="robots" content="noindex, nofollow">` — не индексировать
- [ ] Подключение header-landing.php / footer-landing.php
- [ ] Секции через get_template_part() — переиспользование из Sprint-03

### 2. Компоненты лендинга
- [ ] Hero с изменяемым заголовком/подзаголовком
- [ ] Секция преимуществ (почему мы)
- [ ] Секция услуг (релевантных запросу)
- [ ] Секция примеров работ
- [ ] CTA-блок с формой/телефоном
- [ ] Секция отзывов

### 3. Создание 5 лендингов (волна 1)
- [ ] Лендинг: отопление загородного дома
- [ ] Лендинг: водоснабжение частного дома
- [ ] Лендинг: проектирование инженерных систем
- [ ] Лендинг: электромонтажные работы
- [ ] Лендинг: вентиляция и кондиционирование

> Волна 2 (ещё 7 лендингов) → Sprint-13

### 4. Аналитика
- [ ] UTM-параметры для каждого лендинга
- [ ] Яндекс.Метрика: цели на формы/звонки
- [ ] Отслеживание конверсии по лендингам

### 5. Проверка
- [ ] Все 5 лендингов открываются
- [ ] `<meta robots noindex>` присутствует
- [ ] CTA-кнопки работают: `tel:` ссылка + модальное окно «Заказать звонок» (из Sprint-08) + Telegram
- [ ] Адаптивность на мобильных (основной трафик из Директа)
- [ ] Скорость загрузки < 3 секунд
- [ ] `npm run validate` — 0 ошибок

> **Зависимость:** Модальное окно «Заказать звонок» из Sprint-08 используется как CTA на лендингах. Полная система форм с CPT lead — в Sprint-14.
