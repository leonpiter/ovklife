---

## Контекст

Блог — основной драйвер органического SEO-трафика. Экспертные статьи по инженерным системам привлекают целевую аудиторию через информационные запросы и конвертируют в заявки. Ни один конкурент не имеет глубокого экспертного блога — это наше конкурентное преимущество.

---

## Ключевые решения

| Решение | Обоснование |
|---------|-------------|
| Категории блога = кластеры ключевых слов | Отопление, Водоснабжение, Электрика, Вентиляция, Проектирование |
| CTA-блок в каждой статье | Конверсия: статья → заявка |
| Article Schema + автор | E-E-A-T для Google |
| Содержание (TOC) в длинных статьях | UX + featured snippets |
| Перелинковка статья → услуга → проект | Распределение ссылочного веса |

---

## Типы контента

| Тип | Цель | Пример |
|-----|------|--------|
| Информационные | Long-tail трафик | «Как выбрать котёл для загородного дома» |
| Сравнительные | Средняя частотность | «Тёплый пол vs радиаторы: плюсы и минусы» |
| Коммерческие | Высокая конверсия | «Стоимость отопления загородного дома в 2026» |
| Кейсы | E-E-A-T, доверие | «Монтаж инженерных систем в коттедже 250 м²» |
| FAQ | Featured snippets | «Сколько стоит провести воду в частный дом?» |
