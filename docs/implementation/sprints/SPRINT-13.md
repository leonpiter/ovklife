## Контекст

В Sprint-09 создан шаблон лендинга и 5 лендингов для основных направлений. В Sprint-11 настроены UTM-трекинг и A/B тестирование. В Sprint-12 добавлены расширенные направления услуг. Теперь создаём лендинги для новых направлений и внедряем динамическую подмену контента и A/B тесты.

## Чеклист задач

### 1. Создание 7 лендингов
- [ ] Лендинг: умный дом
- [ ] Лендинг: автоматизация котельной
- [ ] Лендинг: видеонаблюдение
- [ ] Лендинг: мультирум
- [ ] Лендинг: SPA-комплексы
- [ ] Лендинг: установка септика
- [ ] Лендинг: комплексная интеграция

### 2. Динамическая подмена контента
- [ ] Обновить `templates/landing.php` — чтение utm_content из cookie (inc/utm.php)
- [ ] Подмена H1 заголовка по utm_content:
  - `utm_content=variant_a` → «Монтаж отопления от 50 000 руб.»
  - `utm_content=variant_b` → «Отопление загородного дома за 3 дня»
- [ ] Подмена CTA-текста по utm_content
- [ ] Fallback на дефолтный заголовок если utm_content отсутствует
- [ ] Создать `inc/dynamic-content.php` — маппинг utm_content → контент

### 3. A/B тесты на лендингах
- [ ] Тест 1: Квиз (Sprint-10) vs Форма обратной связи
  - Вариант A: CTA → квиз
  - Вариант B: CTA → простая форма
  - Метрика: конверсия в заявку
- [ ] Тест 2: Короткий лендинг (Hero + CTA + Отзывы) vs Полный лендинг
  - Вариант A: все секции
  - Вариант B: Hero + форма + 3 отзыва (минимум)
  - Метрика: конверсия, глубина скролла
- [ ] Передача варианта в Яндекс.Метрику как параметр визита
- [ ] Документирование результатов в `docs/ab-tests.md`

### 4. Оптимизация конверсии
- [ ] Sticky CTA-кнопка на мобильных (фиксированная внизу)
- [ ] Callback-виджет (кнопка «Перезвоните мне»)
- [ ] Таймер акции (опционально, для A/B теста)
- [ ] Exit-intent popup с предложением скидки (для десктопа)

### 5. Аналитика по лендингам
- [ ] Отдельные цели Метрики для каждого лендинга (по URL)
- [ ] Отчёт: конверсия по лендингам (в docs/analytics.md)
- [ ] UTM-трекинг: отслеживание source → лендинг → конверсия

### 6. Проверка
- [ ] Все 7 лендингов открываются, noindex присутствует
- [ ] Динамическая подмена работает с UTM-параметрами
- [ ] A/B тесты: разные варианты показываются корректно
- [ ] Sticky CTA на мобильных не перекрывает контент
- [ ] Скорость загрузки < 3 секунд
- [ ] `npm run validate` — 0 ошибок
