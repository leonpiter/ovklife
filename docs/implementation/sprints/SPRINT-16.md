# Sprint-16: Контентная SEO-стратегия и семантическое ядро

> **Статус:** ⏳ Ожидает
> **Ветка:** `feature/sprint-16-content-seo`
> **Зависимости:** Sprint-15 (миграция завершена), Sprint-07 (блог), Sprint-12 (все услуги)
> **Результат:** семантическое ядро, контент-план на 12 месяцев, оптимизация текстов, Яндекс.Справочник
>
> **⚠️ Примечание:** Это не типичный спринт разработки — это маркетинговый план на 3–6 месяцев. Технические задачи минимальны (оптимизация текстов, SEO мета). Основная работа: контент, регистрация в каталогах, внешние ссылки. Рекомендуется выделить этапы 4–6 (внешняя оптимизация) в отдельный документ `docs/seo/marketing-plan.md` и выполнять параллельно с другими спринтами.

## Контекст

Сайт на WordPress, все технические SEO-задачи решены, миграция с Tilda завершена. Теперь фокус на контентном SEO: наполнение семантического ядра, оптимизация текстов для Яндекса, расширение блога, регистрация в Яндекс.Справочнике и 2GIS, работа с поведенческими факторами.

---

## Ключевые решения

| Решение | Обоснование |
|---------|-------------|
| Кластерный подход к семантике | Каждое направление = кластер ключевых слов = группа страниц |
| LSI-оптимизация текстов | Яндекс учитывает тематическую плотность, не просто ключевики |
| Яндекс.Справочник + 2GIS | Локальный SEO для региональных запросов |
| Контент-план на 12 месяцев | Системное наращивание контента |

## Чеклист задач

### 1. Семантическое ядро (документация)
- [ ] Создать `docs/seo/semantic-core.md` — полное семантическое ядро
- [ ] Кластер «Отопление» — 30+ ключевых запросов с частотностью
- [ ] Кластер «Вентиляция» — 20+ ключевых запросов
- [ ] Кластер «Электрика» — 20+ ключевых запросов
- [ ] Кластер «Водоснабжение» — 20+ ключевых запросов
- [ ] Кластер «Проектирование» — 15+ ключевых запросов
- [ ] Кластер «Автоматизация/Умный дом» — 20+ ключевых запросов
- [ ] Кластер «Видеонаблюдение» — 15+ ключевых запросов
- [ ] Кластер «Мультирум» — 10+ ключевых запросов
- [ ] Кластер «SPA/Бассейны» — 15+ ключевых запросов
- [ ] Кластер «Септик» — 10+ ключевых запросов
- [ ] Маппинг: ключевой запрос → целевая страница

### 2. Оптимизация текстов существующих страниц
- [ ] Проверить и оптимизировать title каждой страницы услуг:
  - Формат: «[Услуга] в загородном доме — OVKLife | Москва и МО»
  - Длина: 50-60 символов
- [ ] Проверить и оптимизировать description:
  - Формат: с CTA (цена, сроки, призыв)
  - Длина: 120-160 символов
- [ ] Проверить H1 на каждой странице (уникальный, с ключевым словом)
- [ ] Добавить LSI-ключи в H2 подзаголовки
- [ ] Проверить объём текста (минимум 2000 символов на страницу услуги)
- [ ] Добавить таблицы цен где отсутствуют
- [ ] Расширить FAQ до 5-7 вопросов на каждой странице

### 3. Контент-план блога на 12 месяцев
- [ ] Создать `docs/seo/content-plan.md`
- [ ] 4 статьи/месяц × 12 месяцев = 48 тем
- [ ] Распределить по кластерам (равномерно по направлениям)
- [ ] Указать ключевые слова для каждой статьи
- [ ] Указать целевую страницу услуги для перелинковки

### 4. Внешняя оптимизация — Этап 1: Базовые регистрации (бесплатно)
- [ ] **Яндекс.Бизнес** (приоритет №1):
  - Название, адрес, телефон, сайт, часы работы
  - Категории: инженерные системы, отопление, вентиляция, электрика
  - Фотографии объектов (минимум 10)
  - Описание с ключевыми словами
- [ ] **2GIS** — карточка компании с полным описанием
- [ ] **Zoon.ru** — профиль компании
- [ ] **Profi.ru** — профиль исполнителя
- [ ] **Яндекс.Услуги** — размещение услуг
- [ ] **Avito (раздел услуги)** — объявления по направлениям
- [ ] **HH.ru** — страница компании (E-E-A-T сигнал)
- [ ] Отзывы: попросить клиентов оставить отзывы в Яндекс.Картах и 2GIS

### 5. Внешняя оптимизация — Этап 2: Отраслевые каталоги

### 7. Внутренняя перелинковка (аудит)
- [ ] Проверить что каждая страница услуги ссылается на:
  - Parent-категорию (если дочерняя)
  - 2-3 смежные услуги
  - 1-2 проекта из портфолио
  - 1-2 статьи из блога
- [ ] Проверить что каждая статья блога ссылается на:
  - Релевантную услугу
  - 1-2 проекта
  - 1-2 другие статьи
- [ ] Создать `docs/seo/internal-links-audit.md` — карта перелинковки

### 8. Поведенческие факторы
- [ ] Проверить CTR в Яндекс.Вебмастере (через 2 недели после миграции)
- [ ] Оптимизировать сниппеты с низким CTR (изменить title/description)
- [ ] Проверить показатель отказов в Метрике по страницам
- [ ] Добавить интерактивные элементы на страницы с высоким отказом
