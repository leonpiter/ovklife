---

## Контекст

Квиз — ключевое конкурентное преимущество. Ни один конкурент в нише (boiler-spb, amikta, sh365) не использует квизы. Квиз квалифицирует лиды: пользователь отвечает на вопросы о своём доме → получает персональный расчёт → оставляет контакты. Конверсия квиза в 2-3 раза выше обычной формы.

---

## Ключевые решения

| Решение | Обоснование |
|---------|-------------|
| Vanilla JS квиз (без библиотек) | Минимальный размер, полный контроль |
| Пошаговый формат | Выше вовлечение, чем форма с 10 полями |
| WP REST API для отправки | Стандартный WordPress способ |
| Email-уведомление + Telegram-бот | Мгновенное оповещение о новой заявке |
| Прогресс-бар | UX: показывает сколько шагов осталось |

---

## Структура квиза

### Шаг 1: Тип дома
- Коттедж / Дача / Таунхаус / Другое

### Шаг 2: Площадь дома
- до 100 м² / 100-200 м² / 200-350 м² / более 350 м²

### Шаг 3: Какие системы нужны?
- Отопление / Водоснабжение / Электрика / Вентиляция / Проектирование
- (множественный выбор)

### Шаг 4: Этап строительства
- Проект / Фундамент / Коробка / Отделка / Готовый дом

### Шаг 5: Когда планируете начать?
- В ближайший месяц / 1-3 месяца / 3-6 месяцев / Пока изучаю

### Шаг 6: Контакты (финал)
- Имя
- Телефон
- Способ связи: Звонок / WhatsApp / Telegram
- «Получить расчёт бесплатно»
