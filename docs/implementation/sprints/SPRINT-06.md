# Sprint-06: Портфолио проектов

> **Статус:** ⏳ Ожидает
> **Ветка:** `feature/sprint-06-portfolio`
> **Зависимости:** Sprint-04 (SEO-инфраструктура)
> **Результат:** архив проектов с подробными кейсами, галереями, Schema.org

---

## Контекст

Для E-E-A-T (опыт, экспертность, авторитетность, доверие) нужно портфолио с подробными кейсами. Конкурент sh365.ru имеет 20+ проектов — нам нужно не меньше. Каждый проект — это SEO-контент и социальное доказательство.

**CPT `project` уже существует** (`inc/post-types.php`, slug `proekty`).
**Фотографии:** 13+ фото из Tilda-экспорта (слайдер Hero) + нужны дополнительные.

---

## Ключевые решения

| Решение | Обоснование |
|---------|-------------|
| Подробные кейсы (не просто фото) | E-E-A-T, длинный контент для SEO |
| Таксономия: тип работ, район | Фильтрация, дополнительные URL для SEO |
| Галерея до/после | Визуальное доказательство качества |
| Ссылки на использованные услуги | Перелинковка, ссылочный вес |

---

## Чеклист задач

### 1. Таксономии
- [ ] Добавить таксономию `project_type` — тип работ (Отопление, Водоснабжение, Комплекс и т.д.)
- [ ] Добавить таксономию `project_area` — район (Всеволожск, Курортный, Пушкин и т.д.)

### 2. Шаблоны
- [ ] Создать `archive-project.php` — архив проектов с фильтрацией
- [ ] Создать `single-project.php` — детальная страница проекта
- [ ] Создать `template-parts/project/content-card.php` — карточка в архиве
- [ ] Создать `template-parts/project/section-gallery.php` — галерея фото
- [ ] Создать `template-parts/project/section-specs.php` — характеристики объекта
- [ ] Создать `template-parts/project/section-related.php` — похожие проекты

### 3. Структура кейса
- [ ] Заголовок (адрес/название объекта)
- [ ] Галерея фотографий (до/после, процесс)
- [ ] Характеристики: площадь, тип дома, выполненные работы
- [ ] Описание: задача клиента, решение, результат
- [ ] Использованные услуги (ссылки на CPT service)
- [ ] CTA: «Хотите так же? Рассчитаем для вашего дома»

### 4. SEO
- [ ] Schema.org: Article или CreativeWork для проектов
- [ ] BreadcrumbList: Главная → Проекты → Название проекта
- [ ] Уникальные title/description с ключевыми словами + район

### 5. Контент
- [ ] Создать 5-10 проектов с фотографиями из Tilda-экспорта
- [ ] Описания, характеристики, использованные услуги

### 6. Пагинация и поиск
- [ ] Подключить `template-parts/common/pagination.php` (из Sprint-05) в `archive-project.php`
- [ ] Фильтрация по таксономиям через AJAX (опционально, можно простые ссылки)

### 7. Проверка
- [ ] Архив /proekty/ отображает все проекты
- [ ] Фильтрация по типу работ и району работает
- [ ] Пагинация работает
- [ ] Детальные страницы с галереями
- [ ] Перелинковка с услугами
- [ ] `npm run validate` — 0 ошибок
