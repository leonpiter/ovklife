# Sprint-15: Миграция с Tilda — 301 редиректы и переключение домена

> **Статус:** ⏳ Ожидает
> **Ветка:** `feature/sprint-15-tilda-migration`
> **Зависимости:** Sprint-01–14 (весь сайт готов)
> **Результат:** бесшовная миграция с Tilda на WordPress, 301 редиректы, сохранение позиций

---

## Контекст

Это финальный этап миграции. Сайт ovklife.ru сейчас на Tilda. WordPress-версия полностью готова (Sprint-01–14). Нужно переключить домен на WordPress без потери SEO-позиций. Ключевые риски: потеря индексации, битые ссылки, дублирование контента.

**ВАЖНО:** Этот спринт выполняется в последнюю очередь, когда весь WordPress-сайт полностью готов и протестирован на staging.

---

## Ключевые решения

| Решение | Обоснование |
|---------|-------------|
| 301 редиректы через PHP | Гибкость, версионирование в Git |
| Маппинг всех Tilda URL | Сохранение ссылочного веса и позиций |
| 410 для удалённых страниц | Сигнал поисковикам: страница удалена навсегда |
| Мониторинг 2 недели | Раннее обнаружение проблем с индексацией |

## Риски и митигация

| Риск | Вероятность | Митигация |
|------|-------------|-----------|
| Потеря позиций в Яндексе | Средняя | 301 редиректы, мониторинг 2 недели |
| Битые внешние ссылки | Низкая | Маппинг всех URL, 301 для старых |
| Downtime при переключении DNS | Низкая | TTL DNS заранее понизить до 300s |
| Дублирование контента | Средняя | Canonical URL на каждой странице |
| Проблемы с SSL | Низкая | Let's Encrypt + проверка до переключения |
