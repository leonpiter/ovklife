# Sprint-04a: Верификация и расширение семантического ядра через Wordstat

> **Статус:** ⏳ Ожидает
> **Ветка:** `feature/sprint-04a-semantic-verification`
> **Зависимости:** Нет (research-спринт, не зависит от кода)
> **Блокирует:** Sprint-05 (страницы услуг), Sprint-09 (рекламные лендинги), Sprint-16 (контент-план), Sprint-17 (геостраницы)
> **Результат:** Верифицированное семантическое ядро 300+ запросов с реальной частотностью, сезонностью и региональным распределением
>
> **⚠️ Параллельный запуск:** Этап 0 (регистрация OAuth, установка инструментов) запускается параллельно с Sprint-03/04. Это research-спринт — не требует готового кода, только доступ к Wordstat API. Регистрация OAuth занимает 1-2 рабочих дня ожидания — запускать как можно раньше.

---

## Контекст

### Проблема

Текущее семантическое ядро (`docs/semantic/SEMANTIC_CORE.md`) содержит ~102 запроса с **экспертной** (не верифицированной) оценкой HF/MF/LF. Реальной частотности из Яндекс.Wordstat нет. Это означает:

- Приоритеты создания страниц могут быть выстроены неверно
- Нет данных о сезонности (когда публиковать контент?)
- Нет региональной детализации (СПб vs ЛО vs конкретные города)
- Объём ядра (102 запроса) недостаточен для 17+ спринтов и 60+ страниц

### Решение

Подключить **бесплатный Yandex Wordstat API** через MCP-сервер к Claude Code и верифицировать + расширить семантическое ядро до 300-400 запросов с реальными данными.

### Почему сейчас, а не в Sprint-16?

Sprint-16 зависит от Sprint-15 (миграция) — это слишком поздно. Данные Wordstat нужны **до** Sprint-05 (страницы услуг), чтобы:
- Правильно выбрать приоритеты: какие услуги верстать первыми
- Сформировать URL-структуру на основе реального спроса
- Подготовить семантику для рекламных лендингов (Sprint-09)
- Определить приоритеты геостраниц (Sprint-17)

## Инструменты

### Основной: Yandex Wordstat API через MCP (бесплатно)

**Методы API:**

| Метод | Что делает | Квота |
|-------|-----------|-------|
| `/v1/topRequests` | Популярные запросы по ключевому слову (до 2000 фраз) | 1 ед./запрос |
| `/v1/dynamics` | Сезонность по дням/неделям/месяцам (с 2018 года) | 1 ед./запрос |
| `/v1/regions` | Распределение по регионам + индекс аффинитивности | 2 ед./запрос |
| `/v1/getRegionsTree` | Дерево регионов (ID для СПб и ЛО) | Бесплатно |

**Лимиты:** 1000 единиц/день, 10 запросов/сек. Квота обновляется в полночь по Москве.

**Бюджет квоты на спринт:**

| Задача | Запросов | Квота |
|--------|----------|-------|
| Частотность 102 текущих запросов (topRequests) | 102 | 102 ед. |
| Расширение 6 кластеров (topRequests) | 6 | 6 ед. |
| Сезонность 20 ключевых запросов (dynamics) | 20 | 20 ед. |
| Региональный анализ 15 запросов (regions) | 15 | 30 ед. |
| Гео-запросы: 13 городов × 5 услуг (topRequests) | 65 | 65 ед. |
| Запросы по типу дома, площади, брендам (topRequests) | ~50 | 50 ед. |
| **Итого** | **~258** | **~273 ед.** |

Укладываемся в 1 день (лимит 1000). С запасом на дополнительные проверки.

### Дополнительный: WordStater (расширение Chrome, бесплатно)

- Ручная проверка спорных запросов в браузере
- Сбор минус-слов для рекламных кампаний (Sprint-09)
- Прогноз бюджета Яндекс.Директ

## Этап 0: Подготовка инфраструктуры

### 0.1 Получение доступа к Wordstat API
- [ ] Зарегистрировать OAuth-приложение на `oauth.yandex.ru`:
  - Платформа: «Веб-сервисы»
  - Redirect URI: `https://oauth.yandex.ru/verification_code`
  - Доступ: «Yandex Direct API»
  - Записать **ClientID**
- [ ] Запросить доступ к API через поддержку Яндекс Директа (указать username + ClientID)
- [ ] Дождаться одобрения (1-2 рабочих дня)
- [ ] Получить OAuth-токен:
  ```
  https://oauth.yandex.ru/authorize?response_type=token&client_id=YOUR_CLIENT_ID
  ```
- [ ] Проверить токен через `/v1/userInfo` — убедиться что квота доступна

### 0.2 Подключение MCP-сервера к Claude Code
- [ ] Установить MCP-сервер:
  ```bash
  claude mcp add yandex-wordstat -e YANDEX_WORDSTAT_TOKEN=ваш_токен -- npx -y yandex-wordstat-mcp
  ```
- [ ] Проверить работу: запросить `getRegionsTree` → получить ID региона «Санкт-Петербург»
- [ ] Тестовый запрос: `topRequests` для «отопление загородного дома спб» → убедиться что данные приходят

### 0.3 Установка браузерного расширения
- [ ] Установить WordStater из Chrome Web Store
- [ ] Зарегистрироваться на uta-manager.ru (бесплатно)
- [ ] Проверить работу: открыть wordstat.yandex.ru, убедиться что панель расширения видна

## Риски и митигация

| Риск | Вероятность | Митигация |
|------|-------------|-----------|
| Отказ в доступе к API | Низкая | Альтернатива: ручной сбор через WordStater + wordstat.yandex.ru |
| Лимит 1000 запросов/день мал | Низкая | Растянуть на 2 дня или запросить увеличение |
| MCP-сервер не работает | Средняя | Альтернатива: прямые HTTP-запросы к API через скрипт (curl/fetch) |
| Частотность сильно отличается от гипотез | Средняя | Пересмотр архитектуры сайта (URL, навигация) |
| API в бете — нестабильность | Средняя | Сохранять сырые данные, иметь WordStater как backup |
