# Sprint-12: Расширенные направления услуг — автоматизация, умный дом, видеонаблюдение, SPA

> **Статус:** ⏳ Ожидает
> **Ветка:** `feature/sprint-12-extended-services`
> **Зависимости:** Sprint-05 (шаблоны услуг, CPT иерархия)
> **Результат:** 25+ новых страниц услуг по расширенным направлениям, полная SEO-оптимизация

---

## Контекст

В Sprint-05 созданы основные 5 направлений (отопление, водоснабжение, электрика, вентиляция, проектирование). Теперь расширяем каталог услуг дополнительными высокомаржинальными направлениями: автоматизация, умный дом, видеонаблюдение, мультирум, SPA-комплексы, септик, обслуживание. Каждое направление — отдельный кластер ключевых слов для Яндекса.

**Шаблоны из Sprint-05 переиспользуются** — single-service.php, archive-service.php, template-parts уже готовы.

---

## Ключевые решения

| Решение | Обоснование |
|---------|-------------|
| Переиспользование шаблонов Sprint-05 | Единый UX, меньше кода, быстрее реализация |
| Каждое направление = parent service | Иерархия: parent → child для глубокой структуры |
| Уникальные FAQ для каждого направления | FAQPage Schema → featured snippets |
| Перелинковка между новыми и старыми услугами | Распределение ссылочного веса |

## Новые направления и структура

### 1. Автоматизация (/uslugi/avtomatizaciya/)
```
├── /avtomatizaciya-kotelnoj/      ← Автоматизация котельной
├── /umnyj-dom/                    ← Умный дом под ключ
└── /dispetcherizaciya/            ← Диспетчеризация инженерных систем
```

**Ключевые запросы:**
- автоматизация котельной загородного дома
- умный дом под ключ / цена / для загородного дома
- диспетчеризация инженерных систем
- дистанционное управление отоплением
- автоматизация климат-контроля

### 2. Видеонаблюдение (/uslugi/videonablyudenie/)
```
├── /proektirovanie-videonablyudeniya/   ← Проектирование систем видеонаблюдения
└── /montazh-videonablyudeniya/          ← Монтаж видеонаблюдения
```

**Ключевые запросы:**
- монтаж видеонаблюдения в частном доме / на участке
- проектирование системы видеонаблюдения
- IP камеры для загородного дома
- видеонаблюдение под ключ

### 3. Мультирум (/uslugi/multirum/)

**Ключевые запросы:**
- мультирум система для дома
- распределённое аудио / домашний кинотеатр
- мультимедиа для загородного дома
- мультирум под ключ

### 4. Установка септика (/uslugi/septik/)

**Ключевые запросы:**
- установка септика / Топас / Юнилос
- автономная канализация для загородного дома
- септик для частного дома цена
- монтаж септика под ключ

### 5. SPA-комплексы (/uslugi/spa-kompleksy/)
```
├── /bassejny/        ← Инженерные системы для бассейнов
├── /hammamy/         ← Хаммамы под ключ
└── /sauny/           ← Инженерные системы для саун
```

**Ключевые запросы:**
- инженерные системы для бассейна / хаммама / сауны
- строительство хаммама под ключ
- вентиляция бассейна / обогрев бассейна
- водоподготовка бассейна

### 6. Комплексная интеграция (/uslugi/kompleksnaya-integraciya/)

**Ключевые запросы:**
- инженерные системы под ключ
- комплексные инженерные решения для загородного дома
- интеграция инженерных систем

### 7. Обслуживание (/uslugi/obsluzhivanie/)
```
├── /servisnoe-obsluzhivanie/   ← Сервисное обслуживание
└── /energoaudit/               ← Энергоаудит и энергоэффективность
```

**Ключевые запросы:**
- обслуживание инженерных систем
- сервисное обслуживание котельной
- энергоаудит загородного дома
- техническое обслуживание отопления
