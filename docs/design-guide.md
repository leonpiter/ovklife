## Цветовая палитра

### Основные цвета

| Токен | Значение | Использование |
|-------|----------|---------------|
| `--color-dark` | `#1e180e` | Навигация, подвал, тёмный фон |
| `--color-text` | `#181818` | Основной текст, заголовки |
| `--color-text-secondary` | `#4d4646` | Вторичный текст, описания |
| `--color-accent` | `#ba9661` | Золотой акцент, подзаголовки, метки |
| `--color-accent-hover` | `#3a2e1b` | Hover-состояние, тёмный акцент |
| `--color-link` | `#ff8562` | Ссылки, активные элементы |
| `--color-light` | `#fafafa` | Светлый фон секций |
| `--color-white` | `#ffffff` | Белый фон, текст на тёмном |
| `--color-gray` | `#838383` | Разделители, декоративные линии |
| `--color-gray-light` | `#bcbcbc` | Мелкий текст, подписи |
| `--color-menu-bg` | `#111111` | Фон мобильного меню |
| `--color-error` | `#ff0000` | Ошибки валидации |
| `--color-focus` | `#2015FF` | Фокус-outline (accessibility) |

### Градиенты

| Токен | Значение | Использование |

### Тени

| Токен | Значение | Использование |
|-------|----------|---------------|
| `--shadow-sm` | `0 0 10px rgba(0,0,0,0.1)` | Карточки, лёгкие элементы |

| `--shadow-lg` | `0 0 20px rgba(0,0,0,0.3)` | Уведомления, модальные окна |

### Прозрачности

| Токен | Значение | Использование |
|-------|----------|---------------|
| `--overlay-light` | `rgba(255,255,255,0.1)` | Лёгкий оверлей |

## Типографика

### Шрифт

**Inter** (Google Fonts) — переменный шрифт, начертания: 300, 400, 500, 600, 700.

```css
font-family: 'Inter', Arial, sans-serif;
```

### Шкала размеров

| Токен | Размер | Вес | Интерлиньяж | Трекинг | Использование |

```css
:root {
  /* Цвета */

  --color-text: #181818;
  --color-text-secondary: #4d4646;
  --color-accent: #ba9661;

  --color-gray-light: #bcbcbc;

  --color-error: #ff0000;

  /* Градиенты */

  --gradient-dark: linear-gradient(180deg, #2C2929, #363434);

  /* Тени */
  --shadow-sm: 0 0 10px rgba(0,0,0,0.1);
  --shadow-md: 0 0 20px rgba(0,0,0,0.2);
  --shadow-lg: 0 0 20px rgba(0,0,0,0.3);

  /* Типографика */
  --font-family: 'Inter', Arial, sans-serif;
  --text-hero: 50px;
  --text-h1: 43px;
  --text-h2: 30px;
  --text-h3: 22px;
  --text-body: 18px;
  --text-body-sm: 16px;
  --text-sm: 14px;
  --text-xs: 12px;

  /* Breakpoints (для документации, в CSS используются в @media) */
  --bp-mobile: 320px;
  --bp-mobile-lg: 480px;
  --bp-tablet: 640px;
  --bp-desktop-sm: 980px;
  --bp-desktop: 1200px;

  /* Скругления */
  --radius-sm: 4px;
  --radius-md: 15px;
  --radius-lg: 20px;
  --radius-xl: 30px;
  --radius-full: 1000px;

  /* Контейнер */
  --container-max: 1200px;
  --container-padding: 40px;
  --container-padding-mobile: 25px;

  /* Переходы */
  --transition-fast: 0.2s ease;
  --transition-base: 0.3s ease;
  --transition-slow: 0.5s ease;
}
```
