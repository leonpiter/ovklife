## ⚙️ ON-PAGE SEO ЧЕКЛИСТ (для каждой страницы)

### Мета-теги:
- [ ] Title: 55–65 символов, главный запрос + гео + бренд
- [ ] Description: 140–160 символов, запрос + УТП + CTA
- [ ] H1: один на страницу, содержит главный запрос
- [ ] H2–H4: структурированы, содержат MF/LF запросы

### Контент:
- [ ] Объём: страница услуги — 1800–2500 слов, статья — 2000–3500 слов
- [ ] Плотность ключевых слов: 1.5–2.5% (не спам)
- [ ] LSI-слова: синонимы, смежные термины (котельная, теплоснабжение, ОВК и т.д.)
- [ ] Уникальность: минимум 85% по Яндекс.

### Техническое:
- [ ] URL: транслит, через дефис, максимум 3 уровня вложенности
- [ ] Alt-теги у всех изображений (запрос + описание)
- [ ] Внутренняя перелинковка: 3–5 ссылок на релевантные страницы
- [ ] Хлебные крошки (breadcrumbs) с Schema.org
- [ ] Schema.org: Service / FAQPage / LocalBusiness

### Скорость (Core Web Vitals):
- [ ] LCP < 2.5 сек
- [ ] FID < 100 мс
- [ ] CLS < 0.1
- [ ] Изображения в WebP, сжатые
- [ ] Lazy load для изображений ниже первого экрана
