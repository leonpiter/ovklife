# OVKLife — Roadmap развития сайта

> **Проект:** OVKLife — Инженерные системы для загородного дома
> **Цель:** Лидерство в поиске по СПб и ЛО, максимум заявок на монтаж
> **Стек:** WordPress 6.7 + PHP 8.2 + Vite 6 + Vanilla CSS (лендинги) + Tailwind CSS (внутренние)
> **Старт:** Апрель 2026

---

## Стратегическая цель

Стать самым посещаемым сайтом по инженерным системам для загородных домов в Санкт-Петербурге и Ленинградской области. Генерировать максимум заявок через SEO (органика) и контекстную рекламу (Яндекс.Директ).

## Конкурентный анализ

| Конкурент | URL | Сильные стороны | Слабости |
|-----------|-----|----------------|----------|
| Boiler-SPB | boiler-spb.ru | JSON-LD, статьи, ценовые пакеты | Нет квиза/калькулятора |
| Амикта | amikta.ru | 2 региона, Schema.org, категории работ | Нет глубокого блога |
| SH365 | sh365.ru | Карточки с ценами, 20+ проектов | Нет калькулятора/квиза |

## Наши конкурентные преимущества

1. **Скорость загрузки** — vanilla CSS/JS, оптимизация Core Web Vitals
2. **Рекламные лендинги** — уникальная страница под каждый запрос
3. **Квизы** — квалификация лидов (ни у одного конкурента нет)
4. **Экспертный блог** — глубокий контент для long-tail SEO
5. **Современный стек** — WordPress + Vite, быстрая разработка
