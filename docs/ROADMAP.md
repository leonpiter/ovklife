# OVKLife — Roadmap развития сайта

> **Проект:** OVKLife — Инженерные системы для загородного дома
> **Цель:** Лидерство в поиске по СПб и ЛО, максимум заявок на монтаж
> **Стек:** WordPress 6.7 + PHP 8.2 + Vite 6 + Vanilla CSS (лендинги) + Tailwind CSS (внутренние)
> **Старт:** Апрель 2026

---

## Стратегическая цель

Стать самым посещаемым сайтом по инженерным системам для загородных домов в Санкт-Петербурге и Ленинградской области. Генерировать максимум заявок через SEO (органика) и контекстную рекламу (Яндекс.Директ).

## Наши конкурентные преимущества

1. **Скорость загрузки** — vanilla CSS/JS, оптимизация Core Web Vitals
2. **Модульные лендинги** — конфигурируемые из секций-кирпичиков под каждый запрос Директа
3. **A/B тестирование** — cookie-based варианты секций с трекингом в Метрику
4. **Квизы** — квалификация лидов (ни у одного конкурента нет)
5. **Экспертный блог** — глубокий контент для long-tail SEO
6. **Прозрачный эксперт** — стандарт монтажа, фотофиксация, команда с лицами (лучшее от конкурентов)

## Архитектура модульных лендингов

Ключевое архитектурное решение — модульная система секций, закладываемая в Sprint-03 и расширяемая в Sprint-09/11/13:

```
Sprint-03: Фундамент
  inc/landing-sections.php → ovklife_landing_section($section, $variant, $override)
  sections/{name}/data.php + default.php → разделение данных и шаблона

Sprint-09: Конфигурируемые лендинги
  inc/landing-config.php → массивы секций для каждого /lp/
  templates/landing.php → рендер по конфигу
  Новые секции: pricing, team, standards, benefits
  Варианты: hero/video, hero/engineer, services/focused

Sprint-11: A/B тестирование
  inc/ab-testing.php → cookie + взвешенный рандом
  Фильтр ovklife_section_variant → подмена варианта
  ab-tracker.js → ym(ID, 'params', {...})

Sprint-13: Масштабирование
  inc/dynamic-content.php → utm_content → override данных
  A/B раунд 2: quiz vs form, short vs full landing
  Sticky CTA, exit-intent popup
```
